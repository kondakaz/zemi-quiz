Git と GitHub は、別のもの

事前に読む

ゲームのセーブ機能のようなもの。
自分の PC の中で動く。

GitHub（ギットハブ）

記録をみんなで置く場所

Google ドライブのようなもの。
自動では同期しない。
push したときだけ置かれる。
サイトとして公開もできる。

リポジトリ ＝ プロジェクトのフォルダ＋変更の記録帳。　GitHub に置く単位。
